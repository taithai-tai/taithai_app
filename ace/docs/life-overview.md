# ACE — คุณอยู่ตรงกลางของการจัดการชีวิต

## สถานะล่าสุด — กลับเป็นคนสีขาว 11 กันยายน 2026

ตามคำขอ เปลี่ยนเฉพาะโมเดลกลางหน้าแรกและภาพสำรองกลับเป็นคนสีขาวมุกเดิม ใช้ `ace-human.bin` และ `ace-human-poster.webp` พร้อม renderer เดิม การหมุน ปุ่มหยุด ระบบลดเอฟเฟกต์และตัวเลือกบริการคงเดิม เก็บการแก้ cache ไว้และเปลี่ยน URL renderer/CSS เป็น `?v=white-human-r3` ไม่มีการเปลี่ยนระบบ AI หรือแบบฟอร์ม ส่วนบันทึกตัวละครด้านล่างเป็นประวัติ ไม่ใช่สถานะปัจจุบัน

## อัปเดตตัวละคร — 11 กันยายน 2026

เปลี่ยนคนขาวมุกเป็นตัวละครอิง `peeps-avatar-alpha.png` ที่ผู้ใช้แนบ: หมวกฟ้า ผมแดงน้ำตาล แว่นกรอบน้ำตาลเข้ม ดวงตาดำ ต่างหูและเสื้อสีหม่น ลำตัวกางแขนขาและการหมุนรอบตัวคงเดิม

โมเดลใหม่อยู่ใน `site/assets/ace-avatar.bin` และสร้างด้วย `scripts/build-avatar-mesh.mjs` มี volume ศีรษะ/หมวก/ผม/จมูก/ต่างหูและกรอบแว่นจริง ใช้การฉายภาพต้นฉบับลงบนผิวด้านหน้าของศีรษะร่วมกับสีพื้นผิว ส่วนด้านหลัง เสื้อผ้าเต็มตัว กางเกงและรองเท้าที่ไม่มีในภาพเป็นการตีความ ไม่ใช่การกู้คืนโมเดล 3D ต้นฉบับจาก PNG

ภาพเดิมเก็บที่ `site/assets/ace-avatar-face.png` โดย bytes/alpha ไม่เปลี่ยน ใช้ร่วมเป็นภาพสำรอง รูปสำรองจึงเป็นภาพครึ่งตัวตามต้นฉบับ ไม่อ้างว่าเป็นโมเดลที่หมุนได้เมื่อ WebGL ใช้ไม่ได้ ไม่มีภาพสร้างใหม่ถูกนำมาใช้ในหน้าเว็บ

ไฟล์ใหม่มี 39,928 vertices, 79,794 triangles, ขนาด 1,437,052 bytes ใช้รูปแบบ ACE4 มีตำแหน่ง normal สี UV และ ambient occlusion การหมุน ปุ่มหยุด โหมดลดเอฟเฟกต์ และฟังก์ชันบริการไม่เปลี่ยน ไม่เพิ่มการเก็บข้อมูลหรือเรียก AI ในส่วนภาพ

การตรวจล่าสุดอยู่ใน TEST_REPORT.md โดยยังไม่มีการตรวจภาพบน Browser/GPU จริง รอคำสั่งเผยแพร่สำหรับการแก้ไขตัวละครรอบนี้

## บันทึกงานคนขาวมุกก่อนหน้า

วันที่: 10 กันยายน 2026

ปรับหน้าแรกตามคำขอให้คล้ายหน้าภาพรวมของแอปสุขภาพ แต่เนื้อหาและฟังก์ชันเป็นการจัดการชีวิตด้วย AI ไม่มีข้อมูลชีพจร คะแนนสุขภาพ การสแกนร่างกาย หรือการอ่านเซนเซอร์

## สิ่งที่เปลี่ยน

- คนสามมิติทรงเรียบสีขาวมุก กางแขนและขา หมุนรอบแกนตั้งครบหนึ่งรอบประมาณ 24 วินาที
- ตัวเลือกจัดแผนงานและดูตัวอย่างสรุปอยู่ซ้าย ร่างข้อความและขอคำปรึกษาอยู่ขวา บนจอแคบเรียงใต้ตัวคน
- ปุ่มแต่ละบริการไป `/demo/?mode=planner`, `summary` หรือ `writer` ซึ่งใช้ฟังก์ชันเดิมจริง
- แผนงานตัวอย่างด้านล่างระบุข้อมูลตัวอย่าง รวม 95 นาทีจากเวลาที่มี 120 นาที และมีทางไปจัดแผนของตัวเอง
- ปุ่มหยุด/หมุนต่อและสถานะเป็นข้อความเว็บ การลดเอฟเฟกต์จากระบบหรือ Footer ทำให้หยุดหมุน
- การวาดหยุดเมื่อซ่อนแท็บหรือเลื่อนพ้นโมเดล ภาพนิ่งสำรองยังอยู่หากไม่มี WebGL หรือเกิดปัญหา

## การสร้างและประสิทธิภาพ

`scripts/build-human-mesh.mjs` สร้าง mesh สามมิติจากรูปทรงปริมาตรที่เชื่อมต่อกัน แล้วจัดเก็บตำแหน่ง normal และ ambient occlusion เป็น signed 16-bit พร้อม triangle indices แบบ 16-bit ไม่ใช่การหมุนภาพแบน

`site/assets/life-view.js` ใช้ WebGL ของ Browser โดยตรง ไม่มีไลบรารีหรือโมเดลจากบุคคลภายนอก จำกัด pixel ratio ที่ 1.5 และขนาดแต่ละด้านไม่เกิน 1,200 px โหลดเฉพาะหน้าแรก ภาพ ข้อความ และ CTA แสดงได้ก่อนการเตรียมโมเดลสำเร็จ

ไฟล์ mesh ขนาด 657,402 bytes, 25,288 vertices และ 50,559 triangles ไม่บันทึกข้อมูลผู้ใช้ ไม่เรียก API ของ AI และไม่ต้องใช้ key เพื่อแสดงภาพสามมิติ

## ภาพสำรอง

`site/assets/ace-human-poster.webp` ขนาด 1,024×1,024 px สร้างจาก imagegen หนึ่งครั้ง เป็นภาพคนสมมติไม่มีใบหน้า แล้วแปลงเป็น WebP พร้อมพื้นโปร่งใส ภาพสำรองสื่อท่าเดียวกับโมเดล แต่เป็นคนละ asset และแสดงเป็นภาพนิ่งเท่านั้น

แนวทาง prompt: ภาพ render คนสมมติวัยผู้ใหญ่ สัดส่วนเป็นกลาง วัสดุขาวมุก ท่ากางแขนเหนือแนวนอนเล็กน้อยและกางขา เห็นมือและเท้าครบ มุมหน้าตรง แสงบนซ้าย มีแสงสะท้อนฟ้าอ่อน/ม่วงอ่อน ไม่มีข้อความ UI อุปกรณ์หรือบริบททางการแพทย์

## สิ่งที่คงไว้

อีก 8 หน้า เมนู Footer ข้อความการศึกษา ราคา CTA และการส่งค่าไปฟอร์มคงเดิม Backend ของ 9arm และ secret ไม่เปลี่ยน แบบฟอร์มยังสร้างสรุปคำขอใน Browser และยังไม่ได้ส่งให้ผู้จัดทำ

## การตรวจ

Build, Worker validation และชุดทดสอบ 6 ไฟล์ผ่าน ตรวจขนาด mesh, normal, indices, การไม่ตัดโมเดลระหว่างหมุนในพื้นที่ 6 ขนาด และ lifecycle ใน DOM/WebGL test doubles รายละเอียดอยู่ใน `TEST_REPORT.md`

ยังไม่ได้ตรวจภาพ 3D บน GPU/Browser จริง การกดและการเลื่อนจริง ภาพทุก breakpoint, Zoom 200% หรือ FPS โปรเจกต์ custom Worker เดิมไม่มี development server ที่ใช้กับระบบ Browser preview ที่มี จึงไม่อ้างผลภาพหน้าจอหรือใช้ภาพจำลองแทน

ก่อนส่งงานควรเปิดหน้าแรกบนมือถือและ Desktop: หมุนครบหนึ่งรอบ → หยุด/หมุนต่อ → ลดเอฟเฟกต์ → เลือกบริการทั้งสาม → ตรวจหน้า Demo และ CTA ขอคำปรึกษา
