ข้อมูลข้างต้นอธิบายเวอร์ชันปัจจุบันเท่านั้น หากระบบเปลี่ยน ต้องปรับหน้านี้ให้ตรงกับการทำงานจริง

ข้อมูลในหน้าทดลอง AI

เมื่อกดประมวลผล ระบบจะส่งเฉพาะข้อมูลงานและเวลาที่กรอก ต้นฉบับตัวอย่างที่เลือก หรือข้อมูลสำหรับร่างข้อความ ไปยัง Backend ของ ACE จากนั้น Backend จึงส่งข้อความดังกล่าวไปยังผู้ให้บริการ AI ภายนอกที่ ACE เชื่อมต่อไว้เพื่อสร้างคำตอบ

ACE ไม่บันทึกข้อความเหล่านี้ลงฐานข้อมูลและไม่ใส่ไว้ในระบบวิเคราะห์พฤติกรรม ข้อมูลและผลลัพธ์อยู่ในหน้าที่เปิดอยู่และอาจหายเมื่อรีเฟรช ปิดหน้า หรือกดล้าง อย่างไรก็ตาม ผู้ให้บริการโครงสร้างพื้นฐานและผู้ให้บริการ AI อาจประมวลผลข้อมูลทางเทคนิคหรือคำขอตามนโยบายของตน จึงไม่ควรใส่ข้อมูลลับ ข้อมูลการเงิน รหัสผ่าน OTP หรือ API key

ตัวอย่างสรุปรองรับเฉพาะเอกสารสมมติที่เตรียมไว้ ส่วน Planner จะคำนวณลำดับและเวลาแบบตายตัวก่อนส่งข้อมูลให้ AI เพื่อขอคำแนะนำเพิ่มเติม หาก AI เชื่อมต่อไม่สำเร็จ ระบบจะแจ้งข้อผิดพลาดและไม่แอบเปลี่ยนเป็นผลจากแม่แบบ

ระบบใช้ตัวระบุเครือข่ายแบบแฮชในหน่วยความจำชั่วคราวเพื่อจำกัดจำนวนคำขอโดยประมาณ และไม่บันทึกตัวระบุดังกล่าวลงฐานข้อมูล

ข้อมูลในแบบฟอร์มติดต่อ

แบบฟอร์มรับชื่อ อีเมล บริการ แพ็กเกจ เรื่องที่อยากให้ช่วย และช่วงเวลาที่สะดวก เพื่อสร้างข้อความสรุปภายในเบราว์เซอร์เท่านั้น ขณะนี้ไม่มีการส่งหรือบันทึกข้อมูลเป็นคำขอปรึกษา

เว็บไซต์ไม่ขอเลขบัตรประชาชน ข้อมูลการเงิน รหัสผ่าน รหัส OTP หรือ API key รวมถึงข้อมูลอ่อนไหว กรุณาอย่ากรอกข้อมูลเหล่านี้

สถานที่เก็บและผู้ที่เข้าถึง

ตัวเลือก “ลดเอฟเฟกต์” เก็บเฉพาะค่าการแสดงผลไว้ในเบราว์เซอร์ของอุปกรณ์นี้ เพื่อใช้ต่อเมื่อเปลี่ยนหน้าหรือกลับมาใหม่ ไม่ได้เก็บข้อความที่พิมพ์ในหน้าทดลองหรือแบบฟอร์มไว้ในค่าดังกล่าว คุณล้างค่านี้ได้จากข้อมูลเว็บไซต์ในเบราว์เซอร์ หากอุปกรณ์เปิดโหมดลดการเคลื่อนไหว เว็บไซต์จะเคารพการตั้งค่านั้นด้วย

ACE ยังไม่ได้กำหนดฐานข้อมูลหรือพื้นที่ส่วนตัวสำหรับเก็บคำขอ เพราะระบบรับคำขอยังไม่พร้อม ผู้จัดทำจึงยังไม่สามารถเข้าถึงข้อมูลที่พิมพ์ในแบบฟอร์มผ่านเว็บไซต์นี้ได้

ปุ่มคัดลอกใช้ความสามารถของเบราว์เซอร์ และปุ่มดาวน์โหลดสร้างไฟล์ข้อความบนอุปกรณ์ของผู้ใช้ การจัดเก็บไฟล์หลังดาวน์โหลดขึ้นอยู่กับอุปกรณ์และการตั้งค่าของผู้ใช้

การส่งต่อและบริการภายนอก

หน้าทดลองส่งข้อมูลที่ระบุข้างต้นไปยังผู้ให้บริการ AI ภายนอกเมื่อผู้ใช้กดประมวลผลเท่านั้น API key ถูกเก็บเป็น Secret ฝั่ง Backend และไม่ถูกส่งไปยังเบราว์เซอร์ ผู้ใช้ไม่ต้องกรอกกุญแจบริการเอง

เว็บไซต์ยังไม่เชื่อมต่อปฏิทิน อีเมล ระบบชำระเงิน หรือบัญชีภายนอก และไม่อ้างว่าได้บันทึกกำหนดการหรือส่งข้อความให้ใครแล้ว โครงสร้างพื้นฐานที่ใช้เผยแพร่เว็บไซต์อาจประมวลผลข้อมูลทางเทคนิคที่จำเป็นต่อการให้บริการหน้าเว็บ

การวัดผล

ยังไม่ได้เชื่อมระบบวิเคราะห์พฤติกรรม จึงไม่อ้างว่ามีการวัดคลิก CTA การเปิดหน้าทดลอง หรือการส่งคำขอแล้ว หากเพิ่มภายหลัง ควรเก็บเฉพาะเหตุการณ์ที่จำเป็น และไม่ใส่ชื่อ อีเมล หรือข้อความของผู้ใช้ในรายละเอียดเหตุการณ์

การติดต่อและขอลบข้อมูล

ยังไม่ได้กำหนดช่องทางติดต่อผู้จัดทำและผู้มีสิทธิ์เข้าถึงข้อมูล เพราะระบบยังไม่รับหรือเก็บคำขอจริง ก่อนเปิดรับข้อมูลต้องเพิ่มชื่อผู้รับผิดชอบ ช่องทางติดต่อ ระยะเวลาเก็บ และขั้นตอนการขอดูหรือขอลบข้อมูลให้ครบ

สิ่งที่ยังต้องเติมก่อนใช้งานจริงผู้ควบคุมข้อมูล ผู้มีสิทธิ์เข้าถึงข้อมูล ช่องทางติดต่อ ระยะเวลาเก็บ ระบบรับคำขอ และรายละเอียดผู้ให้บริการที่เชื่อมต่อ

ทดลองได้โดยไม่เชื่อมบัญชี

ไม่ต้องสมัครสมาชิกหรือกรอก API key แต่ควรใช้ข้อมูลทั่วไปที่ไม่เป็นความลับ และตรวจคำตอบก่อนนำไปใช้
