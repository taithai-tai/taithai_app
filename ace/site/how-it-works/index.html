เริ่มต้นอย่างไร

เริ่มจากเรื่องที่อยากแก้
ไม่ใช่จากเครื่องมือที่ต้องเรียน

เป้าหมายของขั้นตอนนี้คือทำให้คุณรู้ว่าจะเกิดอะไรขึ้น ได้รับอะไร และส่วนไหนที่ยังต้องประเมินก่อนตกลงทำงาน

ขอคำปรึกษาดูก่อนว่า ACE ช่วยอะไรได้

กระบวนการ 4 ขั้นตอน

จากการเล่าปัญหา ไปจนถึงใช้ต่อได้ด้วยตัวเอง

01

เล่าว่าอยากให้ช่วยเรื่องอะไร

บอกเป้าหมาย งานที่ติดขัด และวิธีที่ใช้อยู่ในปัจจุบันเท่าที่สะดวก ในขั้นนี้ยังไม่ต้องเลือกชื่อเครื่องมือ

02

รับข้อเสนอขอบเขตและแพ็กเกจที่เหมาะสม

ACE ช่วยแยกสิ่งที่ทำได้ สิ่งที่ต้องประเมินเพิ่ม สิ่งที่อยู่นอกขอบเขต และแพ็กเกจที่อาจเหมาะ โดยยังไม่ถือเป็นการยืนยันราคา

03

ออกแบบแนวทางและตั้งค่าตามที่ตกลง

จัดทำขั้นตอน แม่แบบ หรือแนวทางเชื่อมเครื่องมือเฉพาะส่วนที่ยืนยันว่าทำได้และอยู่ในขอบเขต

04

ทดลอง ปรับแก้ และเรียนรู้วิธีใช้งานต่อ

ทดลองกับตัวอย่าง ตรวจผลลัพธ์ ปรับตามจำนวนรอบในแพ็กเกจ และเรียนรู้วิธีแก้ไขหรือปรับใช้ด้วยตัวเอง

ก่อนเล่าให้ ACE ฟัง

เตรียมเพียงข้อมูลที่จำเป็น

ไม่ต้องรวบรวมทุกอย่างให้สมบูรณ์ แค่ข้อมูลตัวอย่างที่ปลอดภัยก็ช่วยให้เห็นขอบเขตเบื้องต้นได้

ข้อมูลที่ช่วยให้เริ่มคุยได้

  • เป้าหมายที่อยากได้ เช่น เห็นงานทั้งสัปดาห์ง่ายขึ้น
  • ตัวอย่างงานที่ไม่เป็นความลับ
  • วิธีหรือเครื่องมือที่ใช้อยู่ตอนนี้
  • ข้อจำกัด เช่น เวลาพักหรือรูปแบบข้อความที่ต้องการ

ข้อมูลที่ไม่ควรส่งผ่านแบบฟอร์ม

  • รหัสผ่านหรือรหัส OTP
  • API key หรือกุญแจของระบบ
  • ข้อมูลการเงิน เลขบัตรประชาชน หรือข้อมูลอ่อนไหว
  • เอกสารลับหรือข้อมูลผู้อื่นที่ไม่มีสิทธิ์เปิดเผย
!

การเชื่อมเครื่องมือภายนอกต้องประเมินก่อนความสามารถขึ้นอยู่กับระบบ สิทธิ์การเข้าถึง เงื่อนไขผู้ให้บริการ และขอบเขตที่ตกลงกัน ACE จึงไม่รับประกันว่าเชื่อมได้ทุกเครื่องมือ

พร้อมเล่าเรื่องที่อยากจัดการหรือยัง?

แบบฟอร์มปัจจุบันเป็นโหมดสาธิตสำหรับสร้างสรุป ยังไม่ส่งข้อมูลให้ผู้จัดทำและไม่ยืนยันนัด
