เริ่มใช้งาน

เข้าใช้งานอย่างเป็นขั้นตอน

ไม่ต้องสร้างบัญชีใหม่ ใช้บัญชี Google ของเจ้าของที่ยืนยันอีเมลแล้ว

1

ยืนยันบัญชีเจ้าของ

เข้าสู่ระบบด้วย Google ระบบจะตรวจสิทธิ์ก่อนขอข้อมูลเชื่อมต่อ

2

เปิดหน้าไดรฟ์

เมื่อข้อมูลพร้อมใช้ ปุ่มเปิดไดรฟ์จะแสดงขึ้น หน้าไดรฟ์ภายนอกอาจขอรหัสอีกครั้ง

3

จัดการไฟล์ในไดรฟ์

หากเปิดหน้าไดรฟ์ไม่ได้ ให้ตรวจอินเทอร์เน็ตและเครื่องที่เก็บไฟล์ก่อนลองใหม่

เชื่อมต่อ

ใช้งานจากอุปกรณ์ของคุณ

ข้อมูลเชื่อมต่อจะแสดงหลังยืนยันบัญชีเจ้าของเท่านั้น การเชื่อมต่อ Files, Finder หรือ File Explorer ใช้บัญชีไดรฟ์แยกจาก Google และอาจต้องเข้าเครือข่าย Tailscale ของเจ้าของ

Windows / Notebook

เว็บหรือ File Explorer
  1. ยืนยันบัญชีเจ้าของด้านบน
  2. เปิด Tailscale หากใช้การเชื่อมต่อในเครือข่ายส่วนตัว
  3. ใช้ข้อมูล SMB ที่แสดงด้านล่างในแอปจัดการไฟล์

MacBook / macOS

เว็บหรือ Finder
  1. ยืนยันบัญชีเจ้าของ แล้วเปิด Tailscale หากจำเป็น
  2. ใน Finder เลือก Go แล้วเลือก Connect to Server
  3. ใช้ข้อมูล SMB ที่แสดงด้านล่าง แล้วใส่บัญชีไดรฟ์

iPhone / iPad

เว็บหรือแอป Files
  1. ยืนยันบัญชีเจ้าของและเปิดเครือข่ายที่ใช้กับไดรฟ์
  2. ใน Files เลือก Browse แล้วเลือก Connect to Server
  3. ใช้ข้อมูล SMB ด้านล่างกับบัญชีไดรฟ์

Android / โทรศัพท์

เว็บหรือแอปจัดการไฟล์
  1. ยืนยันบัญชีเจ้าของ แล้วเปิดหน้าไดรฟ์จากปุ่มด้านบน
  2. หากหน้าไดรฟ์ขอรหัส ให้ใช้รหัสของไดรฟ์
  3. แอปจัดการไฟล์ที่รองรับ WebDAV ใช้ข้อมูลที่แสดงหลังยืนยันบัญชีได้
เฉพาะเจ้าของ

ข้อมูลเชื่อมต่อของคุณ

อย่าส่งข้อมูลเชื่อมต่อหรือรหัสของไดรฟ์ผ่านแบบฟอร์มแจ้งปัญหา

SMB — เชื่อมต่อเซิร์ฟเวอร์

ใช้ใน Files หรือ Finder เมื่ออยู่ในเครือข่ายของไดรฟ์

SMB — โฟลเดอร์แชร์

ใช้ตำแหน่งโฟลเดอร์ที่เชื่อมกับไดรฟ์โดยตรง

WebDAV

ใช้กับแอปที่รองรับ WebDAV บัญชีไดรฟ์แยกจากบัญชี Google

มีทางเข้าเว็บไดรฟ์แล้ว แต่ยังไม่มีข้อมูลเชื่อมต่อแอปจัดการไฟล์เพิ่มเติม

เครื่องที่เก็บไฟล์ต้องพร้อมใช้งาน
หากเครื่องปิดหรืออินเทอร์เน็ตขัดข้อง อาจเปิดไดรฟ์ไม่ได้ หน้านี้ตรวจเฉพาะบัญชีและข้อมูลเชื่อมต่อ ไม่ได้ตรวจสถานะเครื่องปลายทาง
