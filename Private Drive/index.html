เริ่มใช้งาน

ง่ายในสามขั้นตอน

ไม่ต้องสมัครบัญชีใหม่ และไม่ต้องติดตั้งแอปหากใช้งานผ่านเบราว์เซอร์

1

เปิดไพรเวทแอป

กดปุ่มด้านบนจากอุปกรณ์ใดก็ได้ที่เชื่อมต่ออินเทอร์เน็ต

2

ใส่รหัสเข้าใช้งาน

กรอกรหัสที่ได้รับ หน้าไดรฟ์จะไม่แสดงไฟล์ก่อนยืนยันรหัส

3

จัดการไฟล์

ดู ดาวน์โหลด อัปโหลด และสร้างโฟลเดอร์ได้จากหน้าเดียว

เชื่อมต่อ

ใช้ได้กับทุกอุปกรณ์

วิธีผ่านเว็บเหมาะสำหรับทุกคน ส่วนการผูกเป็นโฟลเดอร์ WebDAV เหมาะสำหรับเจ้าของไดรฟ์

🪟

Windows / Notebook

Chrome, Edge หรือ Network Location
  1. ใช้ง่ายที่สุด: เปิดหน้านี้แล้วกด “เปิดไพรเวทแอป”
  2. เจ้าของไดรฟ์: เปิด File Explorer → This PC → Add a network location
  3. ใส่ WebDAV URL และบัญชีเจ้าของ สำหรับไฟล์ใหญ่แนะนำ RaiDrive หรือ Cyberduck


MacBook / macOS

Safari, Finder หรือ WebDAV
  1. เปิดผ่าน Safari แล้วบันทึก Bookmark ได้ทันที
  2. เจ้าของไดรฟ์: Finder → Go → Connect to Server
  3. วาง WebDAV URL แล้วเข้าสู่ระบบด้วยบัญชีเจ้าของ
📱

iPhone / iPad

Safari, Home Screen และ Files Provider
  1. เปิดด้วย Safari และใส่รหัสเพื่อเข้าไดรฟ์
  2. กด Share → Add to Home Screen เพื่อใช้เหมือนแอป
  3. หากต้องการให้ปรากฏใน Files ให้ใช้แอป WebDAV Files Provider เช่น Owlfiles หรือ FE File Explorer
🤖

Android / โทรศัพท์

Chrome, Home Screen หรือ WebDAV
  1. เปิดด้วย Chrome แล้วใส่รหัสเพื่อเข้าไดรฟ์
  2. เมนู ⋮ → Add to Home screen เพื่อติดตั้งทางลัด
  3. เจ้าของไดรฟ์สามารถใช้แอปจัดการไฟล์ที่รองรับ WebDAV
สำหรับเจ้าของไดรฟ์
